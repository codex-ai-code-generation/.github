## Troubleshooting Common Issues

Install issues? Reinstall the editor extension and sign in again if completions stop appearing.  
Performance problems? Reduce the context size and close unused files when suggestions become slow.  
License/activation? Check the subscription status if the assistant falls back to a limited mode.  
Compatibility? Match the language version in the prompt, as syntax differs between releases.  
Update failures? Restart the editor after updating the extension to reload its language server.
